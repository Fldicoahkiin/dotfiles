# Layer 0：说人话（硬门槛）

> 改编自 [MrGeDiao/shuorenhua](https://github.com/MrGeDiao/shuorenhua)（可作为独立 skill 安装，跑完整规则集）。这里只留对宣发文案最要命的那几条。

**这是压在所有东西底下的第一道门。** 任何一稿，先过这一关，再谈 [voice-dna](voice-dna.md)（是不是 Flacier）、再谈 [dial-system](dial-system.md)（平台刻度和钩子）。过不了「像不像具体人在说这件事」，后面全不算数。

判据一句话：**把文本从「像模型在表演写作」拉回「像一个具体的人，在这个场景下，随口说这件事」。**

## 铁律：炒作放大真事，别伪造感觉

- **炒作 = 挑哪个真痛点开场、把它框得多尖**。钩子来自具体和一个真让人一愣/一烦的事实。
- **傻逼 = 表演一种没有的情绪、套网红话术**。它先是假的，假就显蠢。
- 提高钩子锐度，**只能靠更具体的真事**，不能靠情绪词和网感话术顶上去。

## 不用黑话大词（生成的文案硬要求）

技术词不是黑话，指不出具体东西的充数大词才是。分清楚：

- **留**（指得出一个具体东西，是可信度）：MCP、TOML、`settings.json`、序列化、transport、`AgentDescriptor`、keychain……
- **删**（充数大词，指不出具体东西）：赋能、助力、驱动、抓手、闭环、生态、一站式、降本增效、沉淀、心智、组合拳、护城河、颗粒度、对齐/拉齐、打通、赛道、破圈、增量/存量、价值释放、能力提升、体验升级……
- **也删**（做营销的人才说的词，开发者不这么说）：痛点、踩过的坑、钩子、软广、种草、安利、引流、赋能开发者。

自检：每个名词问一句「它指一个具体的东西吗？」——指不出来（赋能/生态/心智）就删或换大白话；指得出来（MCP/settings.json）就留。

（注：「痛点/钩子」这类词，skill 内部讲方法论时可以用；禁的是它们出现在**成稿正文**里。）

## 机械雷（脚本管，这里不复读词表）

网感假口语、开场提示层、总结式收尾、赋能式黑话、营销行话、翻译腔（「对于…来说」「随着…的发展」「进行 XX」这一族——独立的 AI tell）、机械排比、加粗滥用、句长均匀、emoji 密度——**词表和阈值全住在 `tools/lint.mjs` 里，写完必跑**：

```bash
node tools/lint.mjs <稿件.md>
```

逐行报命中。误伤（引用、反例）人判后放行，别为过 lint 削真内容。

## 判断雷（脚本查不了，靠读）

1. **二元对比假戏剧**——「不是 X，而是 Y」「这不是 A 的问题，是 B 的问题」。多数删前半，直接说 Y。（lint 会数出现次数，判不判病靠你。）
2. **价值拔高骨架**——「不仅仅是……更是……」「真正的 X 不是……而是……」「最后拼的是……」。把它落回一个具体判断。
3. **无源引用**——「研究表明 / 数据显示 / 业内人士认为」不给出处。删掉铺垫，只留本来就成立的话；别编来源。
4. **自我指涉的开场**——「先交代身份 / 免得看着像软广 / 我做了个东西给大家介绍一下」。宣布自己不是广告，本身就是最大的广告 tell。直接从技术现状进入，让内容自己证明。
5. **表演式谦逊**——「还很糙 / 轻喷 / 求轻喷 / 我们仨天天用不是攒来发帖的」。一次是诚实，每段都来是另一种表演。承认边界一句带过就够，姿态是自信的。

发稿前的完整过法（机械 → 诊断 → 整波）见 [review.md](review.md)——写作时别加载它，写完才读。

## 参考基准：技术论证体，不是段子体

Flacier 认可的味道（见他的宣发底稿）：开门见山讲技术现状 → 一个设计取向之争当主线（如 aghub 增量编辑 vs CC Switch 托管）→ 用「其一、其二、其三」冷静拆解 → 点真实符号（`AgentDescriptor`、`settings.json`、`models.dev`）。**论证和具体撑起全文，不靠个人小故事表演。** 个人经历可以有，一句带过，不是主线。竞品对比做成「这不是实现缺陷，而是设计取向」，立场硬但讲理，不情绪泼冷水。

## 发稿前必做（删完还得像人）

删干净套话只是第一步，很容易剩个「被清理过的 AI」——太平、太匀。还要往这几个方向靠：

- **具体动作 > 抽象拔高**：写谁做了什么、改了什么、看到什么数字。「把 MCP 配一次推到所有 agent」而不是「统一配置能力」。
- **真主语真动作**：承载事实的主语和动作留住，姿态层（「我们需要深入思考」）砍掉。
- **允许普通句子存在**：一句普通事实句够用，就别再补「这说明了什么」。
- **节奏不必齐**：短句长句混着来，像人随口说的。
- **统一语域**：这一篇是聊天就聊天、是技术帖就技术帖，别中途跳成公告或喊单。
- **有边界**：没把握就直说「这个我还没验证 / 还没做」，别替读者下判断，别硬演「我全懂了」。

## cleaner ≠ human（关键区别）

把夸张词削弱**不等于**像人。要把话说**具体**。

- 原文：本次优化显著提升了系统整体性能。
- 只是 cleaner：这次优化提升了系统性能。（还是 AI）
- 才是 human：这次主要改了查询链路，首页接口从 800ms 降到 120ms。

## 一条自检

改完问自己：**这段是一个具体的人在说事，还是一个模型在表演「我很会写」？** 如果为了「更像人」必须编一个原文没有的事实或情绪，那就停住——宁可平实，不要伪造。
