# 参考账号打法

两个可借鉴对象。一个是流量样本（yetone），一个是调性样本（AkaraChen）。取法不同。

---

## yetone（avante.nvim 作者，X 8.6w 粉）—— 流量样本

他的公式：**真诚是壳，骚操作和玩梗是钩，硬核技术信誉是底。**

### 直接能抄（低风险、契合真诚人设）
- **launch 推结构 = 自我矮化 + 私人动机 + 情绪词收尾**。范本：「我一直想把这个断断续续做、自己一直在用的玩具项目发出来……虽然还有很多不足，但今天是它跟大家见面的日子，开心」。全程不喊革命/颠覆/最强。
- **痛点先行、我也是受害者**。产品是「把手弄脏了才做出来的东西」，不是功能清单。
- **每条挂图/GIF/视频，文字只做钩子**。越自信的功能文案越短（「avante.nvim 做了」也能收赞——但那是名气红利，见下）。
- **「我想说的是 X 现在支持 Y 了」**——轻量功能预告模板，弱化通稿感。
- **dogfood 实绩代替数字炫耀**。不晒「支持 22 个 agent！」，而是「顺手用 aghub 把一个 MCP 一次推到我装的所有 agent，还审计了一遍谁有啥权限」。
- **中英文按受众切**：面向全球开发者的功能广播可英文，讲心态/私货用中文。

### 要降剂量（他的量对他安全，对「更真诚」定位偏猛）
- **玩梗密度**。「战术后仰」「双厨狂喜」一条一个是他的节奏；想立真诚人设，梗三五条点一个，且选无攻击性的。
- **贴脸对标大厂/竞品**（「感觉跟我的 X 差不多」）。流量猛但姿态高——**对标痛点，别点名产品**。讲「在 N 个 agent 间同步配置有多痛」，不讲「我比 Cursor 强」。

### 别抄（他的个人特权，没有护城河会翻车）
- **指名点评竞品作者、泼冷水**（他敢说「opencode 作者炫耀代码量少不值得兴奋，因为很多 edge case 没 cover」）。这建立在 18k+24.9k star 的信誉上，被质疑能甩硬核细节接住。aghub 早期绝不点名开炮。
- **公开宣传打竞品 ToS 擦边球的骚操作**。aghub 碰 BYOM/key 本就敏感，宣发要强调「key 存 OS keychain、本地、开源可审计」的正当性，绝不往「绕过谁」讲。
- **一句话甩功能不解释**。那是粉丝已经知道你是谁的红利。新产品每条都要自带上下文。

## AkaraChen / @object_nullll（aghub 作者本人，团队成员，X 3.6k 粉）—— 调性样本

就是三人团队里的他。akr.moe，显示名「吊顶高松灯」，bio「无法停止创造」，GitHub bio「button painter, string concatenator, log alchemist」。**不是流量样本（单条 👍4），是调性样本**——真诚 8 : 炒作 2，正好是团队想要的味道。X 阵地由他发，口径要跟他自己的号一致。

### 可直接继承的手法
- **时事钩子 → 用户具体痛点 → 自家产品顺势接入** 的三段式。范本：「6 月 15 日 Claude Agents SDK 改成单独计费了，这点额度不多，正好我的 client 支持调用，帮你把犄角旮旯的用量刷完😇」。
- **自嘲式低姿态人设金句**。学「无法停止创造」「拧按钮的、拼字符串的」，不写「资深工程师打造」。
- **英文文案极简克制**：「One hub for every AI coding agent」「All you agent, in one desktop」「a quiet chat surface for real agent work」——Linear/Raycast 那派冷淡工具审美，不堆 powerful/seamless。
- **敢自标「软广」**。他博客有篇标题直接叫「openapi-metadata 软广」——先承认是广告，反而降低读者防御。
- **生活化俚语做记忆点**（「犄角旮旯」）。中文推不必端着。
- **个人品牌矩阵**：aghub / 2code / 博客 / GitHub 全收在 akr.moe 主域下，bio 直接列产品，互相导流。

### 注意
- 😇 这类消毒表情偶用点睛，别每条都玩梗——aghub 要建「靠谱工具」信任感。
- 蹭政策时事有时效和站队风险，当调味别当主菜；主线落在产品的持久价值（跨 agent 统一配置、可审计）。

## 一句话取法

**yetone 学「壳」和「钩」（真诚打底 + 会设计钩子），别学「底」（开炮要信誉兜底）。AkaraChen 学「味」（真诚克制、自嘲、极简英文），他就是团队的调性锚。**
