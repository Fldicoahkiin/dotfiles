# 发稿前 review（写完才加载这份；写作时别读，省上下文）

三道，顺序固定：**机械 → 判断 → 整波**。机械的交脚本，判断的用下面的诊断法，最后看整波宣发有没有互相穿帮。

## 第一道 · 跑脚本（机械雷，零上下文）

```bash
node tools/lint.mjs <稿件.md>            # 禁词/翻译腔/排比/句长/emoji/加粗，逐行报
node tools/platform-check.mjs <平台> <稿件.md>   # 标题字数/标签数/280 分块/正文链接
```

命中先修再往下走。词表误伤（引用、反例）人判后放行，别为过 lint 削真内容。

## 第二道 · 诊断（判断雷，脚本查不了）

原则抄自 dbs-ai-check 并内化：**删掉 AI 特征不等于像人——要让这句话找到 Flacier 自己的说法。** 所以每个命中不是「删掉」，是回答一个追问。逐段过，对着问：

| 特征 | 它背后在干嘛 | 追问（答不上就改） |
|---|---|---|
| 术语/知识堆满 | 用密度冒充懂 | 这一堆里，哪个是你真正用来想事的？留那一个 |
| 开场三件套（痛点+承诺+悬念） | 卖焦虑换停留 | 你真想让读者知道的那件事是什么？直接从它进 |
| 情绪词顶钩子 | 拿情绪补选题的懒 | 撑这个情绪的**具体真事**是什么？写它 |
| 「不是 X 而是 Y」假戏剧 | 借否定造深刻 | Y 自己站得住吗？站得住就直接说 Y |
| 价值拔高收尾（真正的…是…） | 给平常事镀金 | 落回一个具体判断，它本来是什么就说什么 |
| 无源引用（研究表明…） | 借权威壮胆 | 出处是什么？没有就删铺垫，留本来就成立的话 |
| 自我指涉开场（免得像软广） | 宣布不是广告 | 删。直接从技术现状进，让内容自己证明 |
| 表演式谦逊（求轻喷/还很糙） | 用姿态换好感 | 边界一句带过了吗？带过就删其余 |
| 收束金句 | 制造「说完了」的仪式感 | 前面说清了吗？说清了就直接停 |

**误伤警告（平台阈值，别一刀切）**：排比在知乎/公众号长文里三次以上才算病，小红书分点天然多，别按长文标准杀；收束金句只在公众号长文里有存在空间，短动态一律删；即刻/推特这种短体不查句长节奏。

**self-check**：追问和改写本身不许犯上面任何一条——改出来的句子再过一遍表。

## 第三道 · 整波（多平台稿一起看）

- **同一个梗只准出现在 1-2 个平台**。把各平台稿的开场例子、签名句拎出来排一排——有人连着刷到两条，能不能看出是模板批量发？（[voice-dna.md](voice-dna.md) 的跨平台铁律）
- 每篇头部的自标签（主线 / 钩子类型 / 选题 / 档位）排一排，**选题是不是真的错开了**，还是同一篇改了改称呼。
- 数字口径一致吗？都对得上 `products/<产品>.md` 吗？

## 输出格式

逐条给：`位置 → 特征 → 背后意图 → 追问/改法（具体到文字）`。不打分、不写总评——修完再跑一遍第一道，两道全过才算过。
