# 两个尺度：语气 和 钩子

一篇文案的调性由两件事决定，得分开看，别混成单一「炒作度」——那会把「语气收着」和「选题偷懒」搅成一个数字。

## 尺度一：语气（话说得多收）

- **1** — 完全平实，像 commit message 或技术文档。零情绪，零感叹号。
- **2** — 平静的开发者口吻，偶尔一句口语。
- **3** — 有点情绪、有口语、有网感，但不表演。
- **4** — 情绪外放，感叹号、语气词、玩梗上强度。
- **5** — 拉满，标题党、情绪轰炸、每句都在喊。

> Flacier 整体偏低。默认落在 1.5–3.5，几乎不到 4 以上。**语气收着是人设。**

## 尺度二：钩子（开头抓不抓人）

跟语气无关——可以很冷静地抛一个很狠的开头。

- **1** — 平铺功能列表，没有选题，「我做了个 X，支持 A/B/C」。
- **2** — 有个模糊的好处，但不痛。
- **3** — 痛点开门见山，第一句就戳到具体的烦。
- **4** — 选题精准 + 有记忆点，标题/封面/首句让人停下来。
- **5** — 前三秒生死线级别，不点进来会难受。

> Flacier 普遍偏高。默认落在 2.5–4.5。**钩子必须到位是铁律**，哪怕语气很平，选题也不能懒。

## 各平台默认档位

| 平台 | 语气 | 钩子 | 一句话定位 |
|---|---|---|---|
| LinuxDo | 1.5 | 2.5 | 开发者真心话，钩子=真问题/真数据/真取舍，不是标题党 |
| Reddit | 1.5 | 2.5 | 英文，反 marketing，"I built X because Y frustrated me" |
| 即刻 | 2 | 3 | build in public 短动态，晒进度心路 |
| PH / README / 官网 | 2 | 3 | 正经但有记忆点，第一屏说清是什么给谁用 |
| 知乎 | 2.5 | 3.5 | 专业长文/回答夹带，标题要有张力 |
| 公众号 | 2.5 | 3.5 | 长文推送，标题抓人但克制版 |
| 推特/X | 3 | 3.5 | launch thread + 演示 GIF，晒数据不招烦（aghub 由 AkaraChen 发，Flacier 自己的项目自己发） |
| 小黑盒 | 3 | 3.5 | 极客+玩家腔，干货与钩子各带一点 |
| B站 | 3 | 4 | 视频，前 15 秒留人，标题封面必须狠 |
| 小红书 | 3 | 4 | 封面标题抓眼，但保留一点正经味 |
| 抖音 | 3.5 | 4.5 | 短视频，前 3 秒定生死 |

这是**默认起点**，不是硬规定。生成时可以按具体选题临时 ±0.5，但要说明为什么调。

## 怎么用这两个数字

写完初稿后自检：
1. **语气超了吗**——数一下感叹号和情绪词，超过该平台档位就往下压。宁可冷一点。
2. **钩子到位了吗**——把第一句/标题单独拎出来，路人看到会不会停？不会就重写，别用「我做了个工具」开头。
3. 两件事分开改。压语气不等于砍钩子，砍钩子不等于收语气。
