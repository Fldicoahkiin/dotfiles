# 即刻 · 平台卡

**档位**：语气 2 / 钩子 3　|　朋友圈里那个认真做事的朋友在自言自语。同行浓度最高、对炒作最敏感，甜点区是「克制的真诚 + 一句自嘲式小得意」。

## 铁律
- **第一人称、口语、碎碎念**。开头直接「我最近做了个……」「我全职上班，业余在做……」，不铺垫不喊口号。
- **过程 > 结论**。爱看你怎么想的、卡在哪、试了 A 又试了 B。原生叙事骨架 =「我被 X 烦透了 → 试了几种笨办法 → 于是做了个东西」。
- **必须包装成「过程分享」而非「产品广告」**。判断标准：这条动态即使读者不点你链接，本身也有阅读价值（一个痛点/一个方法/一个数据）。
- **求反馈代替求下载**。结尾问「你们平时怎么解决这个的」，比「欢迎试用」转化高、更不像广告。
- **数字越小越真越好**：$0、0 到 0.1、连夜做、审核 3 天过了。反感「百万用户」大词。

## 格式硬约束
- 短动态，无标题字段——第一句就是标题，自带钩子。100-400 字最舒服，钩子必须在「展开全文」折叠线以上。
- 一条动态只能挂一个圈子：`#独立开发的日常`、`AI探索站`、`产品安利社`，选最精准的。
- 配 1-3 张截图，手机截图的粗糙感反而更真，不用精修封面。
- emoji 克制（🚀🎉一两个点睛），全篇不超 2-3 个。
- 正式 launch 走**产品发布会**模块（159 元/年，类 PH）；日常 build in public 走圈子动态。两条腿。

## 钩子模板（aghub 版，可直接改用）
1. 「我同时在用 Claude Code、Codex、Cursor、Copilot……然后每次配个 MCP 都要在 5 个地方各贴一遍 JSON。忍了半年，最后自己写了个东西统一管。」
2. 「一个暴论：现在 AI coding agent 越多，配置越是灾难。我数了下自己电脑里散落的 skill、MCP、model key，一共 6 份重复的。周末做了个 Rust 小工具想把它们收成一份。」
3. 「全职上班，业余用 Rust + Tauri 做了个管 AI coding agent 配置的桌面 App，支持 22+ 个 agent。今天把『一次配 MCP、推到所有 agent，改了哪几项自己能 diff』这条跑通了，晒张图。你们平时怎么管这堆配置的？」

## aghub 选题
- **A（日常 build in public）**：`我同时在跑 5 个 AI coding agent，光配置就够我喝一壶——所以做了个统一管理的工具`。主打最能共情的主链路（一次配 MCP 部署到所有 agent），配 1-2 张真实截图，结尾抛「你们怎么管这堆 key 和 skill 的」求讨论。不上功能全家桶。
- **B（方法论钩子·藏产品）**：`把给一个 agent 配好的 skill，原样搬到另一个 agent 上——聊聊我怎么让 AI 配置"可移植"这件事`。讲可移植 skill / 跨 agent 审计这个反直觉发现，.skill 包 + SHA-256 + skills.sh 市场作解法自然带出。这类「有嚼头的实践复盘」在即刻转发率最高。

## 反 AI 味 · 本平台专属雷
「重磅推出/全新一代/一站式/赋能开发者」通稿词、`✨极速✨丝滑✨强大` 排比 emoji、功能罗列体（没有「我为什么做」和「卡在哪」）、无我叙事、过度完美（即刻信「还在路上」，不信「已臻完善」）。

## 正式 launch 建议
几波大功能做完后用产品发布会模块做集中发布，配 A/B 日常动态预热——「日常碎碎念铺垫 + 一次正式 launch」组合拳。
