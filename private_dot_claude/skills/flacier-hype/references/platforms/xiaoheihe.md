# 小黑盒 · 平台卡

**档位**：语气 3 / 钩子 3.5　|　B站弹幕味 + 贴吧老哥味 + 数码折腾佬。梗要真、货要硬，装逼会被拆穿。真诚打底，炒作只放门面那层。

## 铁律
- **梗要真、货要硬**。年轻男性为主、有内容鉴别力、明确不吃粗制滥造。抽象玩梗加分，但硬拗游戏梗/明显不玩游戏比不玩梗更翻车。
- **「我做了个工具 + 免费开源 + 手把手教你用」被接受**，纯硬广被划走。把「我做了个工具」改写成「我受够了 XX，于是……」。
- **主动暴露缺点和边界**涨可信度。**开源+免费+跨平台**在白嫖文化里是硬通货，中和「你是不是来卖东西」的警惕。
- 这里不靠平台分成赚钱（H币激励很低），靠**曝光+精准用户导流**——对开源工具刚好合适。

## 格式硬约束
- 图文长帖，「盒友动态」（泛区）+ 数码板块最自然。段落短、多小标题、配图/GIF/截图穿插。
- 标题口语带钩子可带梗，别标题党到虚假；「问题 + 我给了个解法」句式好使。
- 首图要有信息量（界面/对比/效果），不是纯 logo。
- GitHub/下载放文末，正文把「怎么用、解决了什么」讲完整，别只甩链接。
- **蹭时间窗**：踩某家 agent 更新/涨价/翻车的当口发，起量远高于事后补发。

## 结构骨架
从一个具体场景开局（一句抓眼）→ 先给能立刻用的白嫖价值 → 中段引出 aghub → 实测截图 → 文末开源地址。

## 钩子模板（aghub 版，可直接改用）
1. 「桌面上装了 Cursor、Claude Code、Codex、Copilot 五个 AI，配一个 MCP 要在五个地方各填一遍 key，填到第三个我人已经麻了。周末干脆自己写了个工具把这事儿一次解决——顺便开源了，白嫖不谢。」
2. 「又双叒换 AI 编程工具了是吧？我懂。换一个就得把 MCP、skill、模型 key 重配一遍的痛，谁用谁知道。我做了个东西，让这些配置在所有 agent 之间一次搞定，附教程。」
3. 「自己天天用 AI 写代码，被各家工具各存一套配置烦够了，索性做了个 hub 把 22+ 个 agent 的配置统一管起来——改了哪几项你自己能 diff、删了零残留。讲讲我为什么这么设计。」

## aghub 选题
- **A（主推·白嫖工具叙事）**：借「AI 编程工具满天飞、大家频繁横跳」的热度，把 aghub 定位成「横跳党的存档同步器」。标题《受够了每换一个 AI 编程工具就重配一遍 MCP —— 我写了个开源工具一次搞定，附教程》。
- **B（接老本行）**：Flacier 之前在小黑盒发过 Steam 存档工具，老读者有印象。用「存档/同步/备份」的玩家心智讲 aghub，降低理解门槛。标题《上次讲 Steam 存档，这次讲 AI 编程工具的"存档"：一处配置同步到所有 agent》。
