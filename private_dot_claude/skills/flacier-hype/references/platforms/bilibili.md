# B站 · 平台卡（视频）

**档位**：语气 3 / 钩子 4　|　懂哥之间平视聊天，不是抖音吆喝也不是公众号端着。**内容态度第 1-2 档真诚，钩子和封面按第 3 档工程化用力**——这是上次「钩子弱、流量差」的病根所在。

## 铁律
- **前 3 秒 + 完播率双重绞杀**。0-3 小时初测期若完播 <40%、点赞 <5%，直接停推。所有力气压在前 15 秒钩子和封面。
- **平视，不爹味**。观众默认和你一样是折腾党，行话直接讲（MCP/agent/keychain 不用解释到幼儿园）。「我踩过这坑分享给你」，不是「我来教你」。
- **软广接受度最低（仅 9.22%），直说「这是我做的开源工具」反而加分**。别装第三方客观测评。
- **敢说缺点/竞品好话**。「目前还只支持 xx」「某场景你直接手动改配置也行」——一句真诚顶十句吹。

## 格式硬约束
- 时长 6-8 分钟（科技知识类 5-10 分钟留存最高）。
- 标题公式 `[痛点/疑问] + [解决方案/亮点]` + 具体数字/情绪词/场景。偏好词：干货、保姆级、实测、一口气、手把手、一个视频。
- 封面（点击率生命线）：1146×717，元素 ≤3，大字鲜艳色，一排 ≤6 字、整封面 ≤8 字。黄金法则 **一个主卖点 + 一个冲突词**（「11 个 AI 工具｜配置一次搞定」「重复配置？没必要」）。
- 标签 5-8 个：主词（AI编程）+ 长尾（Claude Code/Cursor/MCP/开源工具）+ 场景（独立开发者/效率工具/Rust）。
- 简介前两行列表页露出：3-5 关键词 + 一句钩子 + GitHub 链接。
- 发布：工作日晚 20:00-21:00。恰饭引导放内容高潮后，「觉得有用 GitHub 给个 star，是对独立开发者最大的鼓励」比「记得三连」自然。

## 视频脚本结构（8 分钟版，可直接套）
```
00:00-00:20  钩子 + 价值承诺（新号加一句自我介绍）
00:20-01:30  痛点铺陈：多 agent 重复配置有多烦
01:30-04:30  主段一：现场演示配一次 → 部署到全部 agent（信息密度最高）
04:30-05:00  节奏切换点（一句自嘲/翻车/转场缓冲）
05:00-07:00  主段二：Skills 跨 agent 共享 / BYOM / Usage 监控挑一个深挖
07:00-07:40  总结 + 观点升华（为什么该有这么个 hub）
07:40-08:00  互动引导 + 下期预告
```
每 3-5 分钟埋一个弹幕互动点或情绪转折，别出现 2 分钟冷区。

## 前 15 秒钩子模板（可直接改用）
1. 「我电脑里装了 11 个 AI 编程工具——Claude Code、Cursor、Copilot、Codex 全都有。然后我发现一件很蠢的事：同一个 MCP，我在每个工具里配了一遍，配了整整十一遍。今天这个视频，就是我怎么让这十一遍变成一遍。」
2. （开头直接放屏录）「注意看这个命令。我敲一次，MCP 配置、skill、模型 key，同步部署到我全部 11 个 AI coding agent。以前这事我要手动改 11 个配置文件——今天我用 Rust 写的这个开源工具，一行搞定。」
3. （翻车自嘲，B站最吃）「三个月前我换了台新电脑重配 AI 编程环境。Claude 一套、Cursor 一套、Codex 又一套……配到第三个我人麻了：为什么 2026 年了我还在给六个工具重复贴同一份配置？于是我干脆自己写了个东西。」

## aghub 选题
- **A（首选·独立开发者叙事）**：《受够了在 11 个 AI 编程工具里重复配置，我用 Rust 写了个开源工具一次搞定》。把「我做了个工具」讲成「重度用户的自救过程」，广告感最低、完播和情感浓度最高，最能修上次的病。
- **B（承接·横评科普向）**：《我把 Claude Code、Cursor、Codex… 全打通了：一份 MCP 配置，喂给所有 AI 编程工具》。先当科普讲清跨 agent 管配置的门道（给社交货币）→ 演示 aghub → 结尾自然带出开源。搜索长尾和破圈更好。

## 反 AI 味 · 本平台专属雷
前 3 秒「大家好我是 XX 今天给大家带来」空转（上条视频的病根）、「在当今时代…让我们一起探索」AI 稿开场、功能罗列 PPT 朗读、封面骗点击（弹幕刷「典」「诈骗」）、硬切广告。

## 视频自动化接口（后续挂载点）
脚本产出统一带三个字段，方便下游视频制作 skill 直接接：
- `分镜`：每段的画面（屏录/真人/对比图/大字卡）
- `旁白`：逐句口播文案（TTS 输入）
- `字幕`：卡点关键词（大字幕，观众常静音看）
