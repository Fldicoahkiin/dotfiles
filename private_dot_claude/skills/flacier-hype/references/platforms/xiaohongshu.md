# 小红书 · 平台卡

**档位**：语气 2 / 钩子 4　|　一个正常开发者随手发一条笔记，不是网红扮用户。钩子靠封面和具体痛点，不靠情绪词。

> ⚠️ 先过 [Layer 0 说人话](../say-human.md)。小红书通用打法爱教你用「谁懂啊/绝绝子/真的会谢」，那对 Flacier 是一眼假——**这张卡是他的个人版，跟通用小红书腔故意不一样**。

## 铁律
- **口语但不是网红腔**：第一人称、平实口语。**网感词（谁懂啊/绝绝子/真的会谢/救命/姐妹们）一律不用**——Layer 0 点名的假口语化，一眼假。也禁「综上所述」「本工具旨在」「首先/其次」。
- **能自称「我做的」，但每篇只露一次，且包在个人故事里**。把「我做了个工具」讲成「我被一个问题烦到自己动手解决了」——痛点是主角，工具是解药。
- **开源/免费前置**，显著降戒心，这个赛道是加分项。
- **专攻 2-3 个卖点**，别面面俱到；术语翻译成人话，别糊一脸 MCP/SHA-256。

## 格式硬约束
- 标题 ≤20 字，关键词塞进前 10 字；数字/痛点/悬念三选一或组合。
- 封面竖版 3:4（1242×1660），大字报「效果词+适用人群」+ 干净界面截图；封面即点击率，模糊封面判低质。
- 图 5-9 张，一图一点，留白别堆字。
- emoji 当分隔/情绪强调（✨❗🔥✅），别当图标铺满。
- 标签 3-5 个，挂 50 万+讨论量话题词。
- 发布：工作日 12-13 点、19-21 点。收藏权重高，结尾引导「先收藏再慢慢配」。

## 结构骨架
1. 钩子：一句扎心痛点 / 反常识结论（前 3 行定完读率）
2. 「我之前有多烦」：具体场景 + 情绪
3. 「我发现了 X」：自然带出工具，别急着报参数
4. 分点讲 2-3 个爽点，每点配一张截图
5. 收尾：一句落回主线（配置还是你的）+ 3-5 标签。别单列「适用人群」、别硬加「你们也试试」的求互动收尾

## 钩子模板（aghub 版，可直接改用 · 都过了 Layer 0）
1. 「同时用 Claude Code、Cursor、Codex 的人应该有体会：想给它们加同一个 MCP，得挨个打开配置各填一遍。我上周填了三遍还填错一个，干脆自己做了个工具管这事。」
2. 「我把 22 个 AI 编程工具的配置统一到了一个地方——MCP 配一次推给全部，一个工具里的 skill 打包一下别的工具直接能用，key 存系统钥匙串。开源免费。」
3. 「换台电脑重配 AI 编程环境，Claude 一套、Cursor 一套、Codex 又一套，配到一半我就想：这活儿不该人来干。于是写了个 aghub。」

> 对照反例（Layer 0 不通过，别这么写）：「谁懂啊……复制粘贴 8 遍😭 直到我自己写了个东西，真的会谢」——表演情绪 + 网感词，一眼假。

## aghub 选题
- **A（主推）**：所有权这条线。炒作标题「用了大半年 CC Switch，我最后还是自己写了一个」；封面大字「配置是你的，别让工具替你保管」+ 桌面 App 截图；正文讲 CC Switch 托管让你说了不算 → aghub 只改你指定的、能 diff、随时收回 → 裸链接结尾，不硬求互动。
- **B（承接·打精准重度用户）**：省钱+安全子选题。标题「AI 编程一个月烧多少钱？我做了个能跨 agent 看用量、还把 key 锁进钥匙串的工具」；BYOM + Usage 监控切「怕超支、怕 key 泄露」。
