# 抖音 · 平台卡（短视频）

**档位**：语气 3.5 / 钩子 4.5　|　对着镜头跟你抢那 3 秒注意力。**钩子可以炒，产品不能吹**——表达形式放开，价值主张真诚。

## 铁律
- **前 3 秒定生死**。第 1 秒就甩钩子（冲突/反转/悬念/利益），文案+画面同步冲击。冷启动阶段完播率 > 互动率 > 复播率 > 转粉率。
- **产品当配角，痛点当主角**。80% 演「这有多烦」，20% 才轻描淡写「后来我用了个工具/我自己写了个东西」。
- **「我自己做的」是抖音稀缺的真诚牌**。独立开发者身份本身是钩子——「一个人写了个工具，管住 22 个 AI 编程 agent」。
- **别浮夸别 AI 味**。面向程序员，喊「震惊！神器颠覆」会被同行当笑话、掉信任。

## 格式硬约束
- 竖屏 9:16，15-45s 最稳，超 60s 完播明显掉。一条只讲一个功能，别塞全家桶。
- 全程大字幕，关键词加粗放大，跟 BGM 鼓点卡点（观众常静音刷）。用上升期热门 BGM。
- 标题短、带钩子、埋垂类词（AI编程/Cursor/Claude Code/MCP）方便打标签；带提问或反差。
- 话题标签 3-5 个：大词（#AI编程 #程序员）+ 精准词（#cursor #claudecode #mcp #独立开发者）。
- 封面竖屏放最狠的钩子大字 + 「混乱 vs 清爽」对比图，封面文字 ≠ 标题（二次信息）。
- 发布：工作日 12-14 点、18-22 点。
- **导流走「评论区置顶 + 主页简介」而非视频口播**：口播说「叫 aghub，开源的」比「点链接下载」安全（露 logo/二维码/明说去 GitHub 会判站外引流降权）。

## 结构模板
钩子（0-3s 痛点/结论）→ 冲突放大（3-8s 演示有多烦）→ 方案揭晓（8-20s aghub 一个动作搞定）→ 记忆点收尾（一句 slogan / 悬念钩评论）

## 前 3 秒钩子模板（可直接改用）
1. （痛点+反差）「别划走——你是不是也这样：Cursor 里配一遍 MCP，Claude Code 里再配一遍，Codex 里又配一遍……我受够了，所以我把它们全接到了一个地方。」
2. （反常识结论）「我删了 22 个 AI 编程工具里的配置文件，一个都没重装。因为这个东西，一次配好，全同步。」
3. （自曝身份+悬念）「一个独立开发者，为什么要花半年写一个『只管配置』的工具？因为我算了下，光重复配 MCP 我这辈子要浪费几百个小时。」

## aghub 选题
- **A（主推·痛点演示型）**：分屏快速演示在 Cursor/Claude Code/Codex 里各配一遍同一个 MCP，报错、复制粘贴、抓狂，然后一个动作 aghub 全同步。标题《同时用好几个 AI 编程工具的人，这条能省你几百个小时》。结构：0-3s 痛点结论 → 3-10s 演示有多烦 → 10-25s 一次同步 → 「叫 aghub，开源，我自己写的」。
- **B（人设·独立开发者故事型）**：一个人为什么写这工具，讲成故事，弱功能强真诚。标题《一个独立开发者，用 Rust 写了个东西管住 22 个 AI 编程助手》。养垂直人设，为后续每功能拆单条视频铺路。

## 反 AI 味 · 本平台专属雷
开头自我介绍（前 3 秒必被划走）、书面语/术语堆砌念稿味、万能音+AI 数字人念稿（当前最泛滥的 AI 味，真人出镜/真实录屏反而稀缺）、无冲突平铺、夸大承诺。
