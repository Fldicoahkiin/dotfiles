## 句式特征

- **长短混排，单句成篇是招牌。** 大功能配长句叙事（第 1、3 条一整段不换行讲来龙去脉），小更新直接一句话甩出去：「avante.nvim 做了」「我想说的是 Alma 现在支持大多数文件格式的内容预览了」「我今天给大家测一下这个 workflow」。**越自信的功能，文案越短**——把解释权交给附带的截图/视频。
- **「我想说的是……」开头模板**（第 7、8 条）。像跟朋友聊天时突然想起来补一句，弱化「官方发布」的仪式感。
- **括号插入语当内心 OS 用，而且经常不闭合括号**：「（什么叫 AI Native，战术后仰」「（注意是所有的）」「（前面的流程忘了录了，但是可以打开声音看最后一个阶段的视频」。不闭合的括号是他的个人指纹——制造一种「话说到一半自己乐了」的即兴感。
- **语气词收尾，不用句号收严肃感**：「开心」「双厨狂喜！」「战术后仰」。结尾一个情绪词，不写「欢迎大家使用」这种通稿话术。
- **技术词中英夹杂、不翻译**：tool calling / multiple steps turn / edge cases / curated context / workspace / system prompt / ACP 直接嵌进中文句子。读者默认是同行。
- **emoji 克制**：🥰🧠 偶尔点缀在英文短推，中文长推几乎不用 emoji。emoji 是「态度标点」而非装饰。

## 宣发手法

- **公布新 feature**：三种档位。① 大功能=长叙事+「今天/刚刚给 X 加了 Y」+顺带一句反思（第 3 条那种「我才知道这叫 curated context」）；② 中功能=「我想说的是最新版 X 支持 Z 了！」+图 1图 2图 3 编号导览（第 7 条）；③ 小功能=一句话+视频，不解释（第 8 条）。**几乎每条都挂图或视频**，文字只做钩子。
- **晒 star/数据**：档案里几乎没有「我们破 X star 啦，感谢大家」这类里程碑推。他晒的是**能力证据**而非数字——用「给 kimi-cli 提了个 PR」(第 6 条) 这种 dogfood 实绩代替数字炫耀。数字留给别人替他说（第 19 条社区背书）。这是他区别于多数「晒 star 截图」独立开发者的关键。
- **处理竞品对比=最狠的一招**：**引用对方的对比推，把自己塞进第三列。** 第 13 条是范本：别人发「VS Code Copilot vs Cursor」，他直接引用+补一句「vs avante.nvim (claude-3.5-sonnet) 🥰」，白嫖了原推的全部流量和对比框架，1k 赞、48w 阅读、1077 收藏。第 9 条同理，看到 Perplexity 出 model committee，立刻「感觉跟 Alma 的 Agent Crew 差不多」贴脸对标大厂。
- **launch 推**：第 1 条是教科书。**先自我矮化（「玩具项目」「还有很多不足」），再讲私人动机（「我一直都很喜欢 ChatGPT 的内置记忆」），最后落到一个情绪词（「开心」）。** 全程不喊「革命/颠覆/最强」，靠真诚和一个 513K 阅读的钩子。

## 三桶：可借鉴 vs 要降剂量 vs 是他的个人特权

### ✅ 可借鉴（直接抄，风险低、契合真诚人设）

1. **launch 推的「自我矮化 + 私人动机 + 情绪词收尾」结构**。aghub 版：「我受够了在 Claude / Cursor / Codex 里一遍遍重复配 MCP 和 key，所以给自己写了个 aghub……本来只是自用的小工具，今天拿出来见见大家，开心」。真诚且天然共鸣。

4. **「我想说的是 aghub 现在支持 X 了」的轻量功能预告模板**——弱化通稿感。
5. **dogfood 实绩代替数字炫耀**。学第 6 条：不晒「支持 22 个 agent！」的数字，而是「顺手用 aghub 把一个 MCP 一次性推到我装的全部 agent，审计了一遍谁有哪些权限」的实操展示。

### ⚠️ 要降剂量（他的量对 yetone 安全，对「更真诚」定位偏猛）

1. **玩梗密度**。「战术后仰」「双厨狂喜」这类梗一条一个是 yetone 的节奏；想立真诚人设的人**梗要稀一点**——三五条里点一个，且选无攻击性的梗。否则真诚感被痞味盖过。
2. **贴脸对标大厂/竞品**。第 9、13 条「感觉跟我的 X 差不多」这种打法流量猛但姿态高。Flacier 可以做对比，但**建议对标「痛点」而非「点名产品」**：讲「在 N 个 agent 间同步配置有多痛」，而不是「我比 Cursor 的 X 强」。
3. **不闭合括号 / bio 摆烂**。是很好的个人指纹，但属于「已经有名气后的松弛感」。新号阶段先把话说清楚，风格化留到有辨识度之后。

### ⛔ 是他的个人特权（别直接抄，抄了会翻车）

1. **指名点评竞品作者、泼冷水**（第 11 条）。这建立在 18k+24.9k star 的技术信誉 + 被质疑能甩硬核细节接住之上。**没有这个护城河的人这么干 = 拉仇恨且接不住反驳**。aghub 早期绝不点名开炮。
2. **公开宣传打竞品 ToS 擦边球的骚操作**（第 5 条反代 Cursor 模型）。yetone 有名气兜底、且他敢担这个风险；aghub 作为「统一管理配置」的工具，**碰 BYOM / key 本就敏感**，宣发上要强调「密钥存 OS keychain、本地、开源可审计」的正当性，不要往「绕过谁」的方向讲。
3. **一句话甩功能不解释**（「avante.nvim 做了」也能收赞）。这是名气红利——粉丝已经知道 avante 是什么。**新产品每条都得自带上下文**，不能指望读者已经懂你在说什么。
