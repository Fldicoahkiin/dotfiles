# 小黑盒 文风简报

> 被宣发项目：aghub —— One hub for every AI coding agent。统一管理 22+ 个 AI coding agent（Claude Code / Codex / Cursor / Windsurf / Copilot / Gemini / OpenCode / Zed / Warp / Cline / RooCode …）配置的 CLI + Tauri 桌面 App。管 MCP、可移植 Skills、Claude 插件市场、BYOM 自定义模型 provider、每 agent 独立选模型、Usage 用量监控。Rust + Tauri 2，跨平台开源。
>
> 目标平台：小黑盒。定位「高能玩家聚集地」，游戏社区 + 泛科技/极客受众。发文者 Flacier：真诚、独立开发者气质，也想要流量，此前在小黑盒发过 Steam 存档工具解析，有一点基础。
>
> 标注约定：[检索所得] = 本轮 WebSearch/WebFetch 拿到的真实资料；[经验推断] = 结合平台社区文化认知补足，非实证。检索受限说明：知乎两篇作者视角贴（269342720、379792018）与作者收益贴均 403 抓取失败；小黑盒站内为 App 内 UGC，无公开可抓的爆款原文，故下文所有「开头钩子/标题」均为按平台腔调**新写的示范**，非抄录真实爆款。

## 原生语感

小黑盒的人说话像「B站弹幕味 + 贴吧老哥味 + 一点数码折腾佬」。用户画像偏年轻男性为主（有测评给出约 23–32 岁、男 66% / 女 34%，与 B站、抖音重合度高），目的性强、有内容鉴别力，明确「不吃粗制滥造」[检索所得]。所以调性是：口语、不端着、爱玩梗爱抽象，但一旦你要「教我点东西」或「给我个好用的」，他们又很认干货、认实测、认「作者是真自己在用」。一句话——**梗要真、货要硬，装逼会被拆穿，AI 感的软文直接划走**[检索所得+经验推断]。

## 什么内容能起量

- **蹭正在爆的热点 + 做成工具**。平台的经典起量案例就是《黑神话》地图功能——热点本身把流量顶到「奥运会级」，谁先上线工具谁吃先发红利（先发方拿到百度指数高 1 倍、B站播放 15 倍的差距）；且工具解决的是「几乎所有玩家的刚需」，用户画像高度重合 → 精准导流而非泛流量 [检索所得]。对 aghub 的映射：把「Cursor / Claude Code 又更新了 / 又崩了 / 又涨价了」这类当下热点，就地做成「我这有个统一管配置的工具，一次解决」。
- **"折腾佬白嫖 / 一个工具解决一堆麻烦"类实用帖**。社区有强烈的「白嫖 / 神器 / 省事」文化（H币白嫖游戏就是母题），效率工具、免费、开源、省钱、省事的钩子天然对味 [检索所得+经验推断]。
- **KOL / 作者输出的干货长图文**。社区模式偏贴吧，优质内容主要靠 KOL 与作者输出，官方自产少；一篇结构清楚、有实测截图的教程/评测容易被筛进热帖、进首页推荐 [检索所得]。
- **"我自己做了个东西"的独立开发者叙事**。真诚、能看到人、有过程感的自制帖，在泛科技/极客受众里吃香；配合可复现的教程更稳 [经验推断]。
- **时效性 + 标准化可复用**。踩着版本更新/新工具发布的时间窗发，比事后补发起量高得多 [检索所得]。

## 什么显 AI 味 / 显尬 / 显硬广（要避开的雷）

- **通稿腔、参数罗列、"赋能/生态/一站式解决方案"这种 PR 词**。这里的人对「粗制滥造」和标题党特别敏感，一股新闻通稿味会被直接判定软文 [检索所得]。
- **全程夸自己产品、零缺点、零对比**。没有「我踩过什么坑 / 它现在还缺什么」的帖子，可信度立刻掉档 [经验推断]。
- **硬拗游戏梗但明显不玩游戏**。抽象玩梗是加分项，但玩错梗/尬蹭比不玩梗更翻车——玩家一眼看穿「这人是来投广告的」[经验推断]。
- **纯外链引流、正文什么都没有**。平台对标题党/纯引流有处罚倾向，把干货全放站外会被判定薅流量 [检索所得+经验推断]。
- **排版一坨、没有截图/GIF**。数码折腾受众吃「眼见为实」，纯文字吹功能没有演示，说服力约等于零 [经验推断]。

## 格式与硬约束

- **发布入口**：图文长帖为主，App 内有图文模板降低发帖门槛；两大内容域——「盒友动态」（泛话题综合区，游戏/数码/生活/八卦都能发）与「社区/版块」（各游戏、数码硬件等垂直板块）。数码硬件、软件折腾类内容落在泛动态 + 数码板块更自然 [检索所得]。
- **篇幅**：中长图文，段落短、多小标题、配图/GIF/截图穿插。移动端阅读，段落别太长 [经验推断]。
- **标题**：口语化、带钩子、可带一点梗，但别标题党到虚假；「问题 + 我给了个解法」的句式好使 [检索所得+经验推断]。
- **封面/首图**：要有信息量的截图（界面/对比/效果），不是纯 logo。数码受众看首图判断「值不值得点」[经验推断]。
- **推荐机制**：定期筛热帖进热点页/首页；先发 + 蹭热点 + 工具性内容组合最容易被推 [检索所得]。
- **创作者激励**：有 H币/返现体系。一级作者只有 H币（1:1000）无现金；二级作者起有收益，约 10w 点击 ≈ 55 元；参与创作计划门槛示例：作者等级 ≥1、近 30 天无违规、≥50 活跃粉丝、30 天内发 ≥2 或 5 篇 [检索所得]。→ 结论：**这里不是靠平台分成赚钱的地方，是靠"曝光 + 精准用户"导流的地方**，对 aghub 这种开源工具刚好合适。

## 自我推广的容忍度与原生包装方式

**容忍度：中。** 直接打硬广会被划走/举报，但「我做了个工具 + 免费开源 + 手把手教你用」这种**以干货为主、产品作为解法出现**的帖子是被接受的——尤其独立开发者叙事在极客受众里有天然好感 [检索所得+经验推断]。

原生包装法：
- **把"我做了个工具"改写成"我受够了 XX，于是……"**。从痛点出发（重度用多个 AI agent、到处重复配 MCP/skill/key），产品是痛点的自然结局，不是开场白。
- **先给白嫖价值再露产品**。开头就给能立刻用上的干货（比如「多 agent 配置怎么不重复劳动」的思路/手法），中段自然引出 aghub 是把这套自动化了。
- **主动暴露缺点和边界**。「目前只支持到 X / 还没做 Y / 这些坑我还没填」——反而涨可信度，符合社区反通稿口味。
- **开源 + 免费 + 跨平台当护城河**。这三个词在白嫖文化里是硬通货，能中和「你是不是来卖东西」的警惕。
- **别在正文外只甩链接**。GitHub / 下载地址放文末，正文把「怎么用、解决了什么」讲完整。

## 3–4 个原生开头钩子示例（按小黑盒母语腔新写，可直接借用）

> 说明：以下为**示范文案**，非真实爆款抄录。

1. **痛点抽象流**
   「桌面上装了 Cursor、Claude Code、Codex、Copilot 五个 AI，配一个 MCP 要在五个地方各填一遍 key，填到第三个我人已经麻了。周末干脆自己写了个工具把这事儿一次解决——顺便开源了，白嫖不谢。」

2. **热点搭车流**（踩某家更新/涨价的时间窗）
   「又双叒换 AI 编程工具了是吧？我懂。换一个就得把 MCP、skill、模型 key 重新配一遍的痛，谁用谁知道。我做了个东西，让这些配置在所有 agent 之间一次搞定，附教程。」

3. **折腾佬白嫖流**
   「今天分享个能救回你半条命的开源工具：一处配置，全家桶 AI agent 同步生效，MCP / skill / 模型 key 再也不用手动搬来搬去。Rust 写的，跨平台，免费。上图。」

4. **真诚独立开发者流**
   「独立开发，没什么大厂背景，就是自己天天用 AI 写代码被配置折磨到破防，索性做了个 hub 把 22 个 agent 的配置统一管起来。这帖讲讲我为什么做、它现在能干嘛、还差哪些。轻喷。」

## 真诚⇄炒作该落在第几档

**建议：2 档（偏真诚克制，只允许一点点钩子上的抓眼）。**

理由：小黑盒受众有强内容鉴别力、明确反感通稿和标题党，且对「一眼软广」高度警觉 [检索所得]；aghub 又是开源工具、Flacier 是独立开发者人设，硬炒作会同时砸掉产品可信度和个人口碑。但平台本身吃热点、吃钩子、吃玩梗，纯 1 档（干到没有情绪）会起不了量。**落点：内容主体真诚克制（实测/痛点/暴露缺点），只在标题和开头一句上用平台化的抽象腔和白嫖钩子去抓眼**——真诚打底，炒作只放在门面那一层。
