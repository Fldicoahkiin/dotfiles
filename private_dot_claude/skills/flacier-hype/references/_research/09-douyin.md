# 抖音（短视频）文风简报

> 面向 aghub 宣发。调研方法：6 轮中英文 WebSearch + 2 个真实爆款开头模板页面抓取（人人都是产品经理「120 条黄金三秒」、青瓜传媒「33 个开头模板」）。抖音社区里数码/开发者垂类的具体口头禅、审核判定标注 [检索所得]，社区文化细节结合平台认知标注 [经验推断]。未编造任何"爆款原文"，引用的例句均来自公开模板文章。

---

## 原生语感（这里的人到底怎么说话、什么调性）

抖音不是"读文案"，是"对着镜头跟你说话"。口播腔调=有一个具体的人在跟屏幕另一头的你抢那 3 秒注意力，语速偏快、句子短、动词前置、一句一个信息点。开头永远先给冲突/悬念/利益，不铺垫、不打招呼、不说"大家好我是"。数码科技垂类的调性介于"神器安利"和"专业测评"之间：既要有"我发现个好东西"的分享欲，也要有"我懂行"的可信度，但表达上必须极度口语——"这玩意儿""直接""真的会谢""别划走"。相比小红书的种草软糯、B 站的娓娓道来，抖音是**最不耐烦、最要即时爽感**的平台，信息密度要么极高（干货型）要么极低（情绪型），中间地带最容易被划走。

---

## 什么内容能起量（越具体越好）

- **"重复劳动痛点"的即时可视化**：前 3 秒直接演示"在 6 个工具里各配一遍 MCP"的地狱操作（快速切窗口、复制粘贴、报错），把"折腾"拍出来，观众秒懂痛点 [经验推断，符合黄金三秒"制造焦虑/痛点"逻辑]
- **"一个动作解决 N 个"的对比爽感**：左边"以前"（手动配 22 个 agent）↔ 右边"现在"（aghub 一次同步），前后对比是科技区最稳的完播结构 [经验推断]
- **强完播率是命根子**：冷启动阶段完播率＞互动率＞复播率＞转粉率，前 3 秒留存直接决定进不进下一个流量池 [检索所得]
- **反常识/反直觉钩子**："我把 22 个 AI 编程工具的配置全删了""再也不在 Cursor 里手动配 MCP 了"——先抛结论制造认知缺口 [检索所得，黄金三秒"认知缺口"底层逻辑]
- **"谁懂啊"式共鸣**：精准戳一小撮"同时开着 Claude Code + Cursor + Codex"的重度用户，垂直标签越准，系统推得越对 [检索所得，垂直度决定打标签]
- **卡点信息流**：干货型用文字卡 BGM 节奏，一个鼓点甩一个卖点，1.5-2 秒一屏，逼观众看到底 [经验推断]
- **数字/清单化**："5 秒把一个 skill 同步到所有 agent""22 个工具，1 个配置"——数字降低理解成本 [检索所得，清单型是稳定套路]
- **更新频率与人设垂直**：账号要垂直（别今天讲 MCP 明天讲炒股），系统才知道推给谁；持续更新养期待感 [检索所得]

## 什么显 AI 味 / 显尬 / 显硬广（要避开的雷）

- **开头自我介绍**："大家好，我是做独立开发的 Flacier，今天给大家带来一款工具"——这是最典型的死法，前 3 秒必被划走 [经验推断]
- **书面语 / 术语堆砌**："本工具旨在统一管理多 agent 的 MCP 配置与可移植 Skills"——念稿味＝AI 味。要改成"你是不是也受够了在每个工具里重配一遍" [经验推断]
- **画面长时间挂 logo / 出现下载二维码、微信、GitHub 链接**：超过 3 秒露出商品 logo / 二维码 / 联系方式会被判营销广告并降权 [检索所得]
- **诱导站外**：口播/评论/主页明说"链接放评论区""去 GitHub 搜"会被判"站外引流"降权，得用更隐晦的方式（见下节）[检索所得]
- **夸大功能 / 不实**："一键解决所有 AI 编程问题"这种过度承诺，系统和观众都反感 [检索所得，夸大效果=营销判定]
- **无冲突的平铺**：老老实实"介绍功能一二三"没有痛点前置，完播率崩，等于没发 [检索所得]
- **万能音 + 数字人脸**：套模板配音 + AI 数字人念稿是当前最泛滥的 AI 味来源，真人出镜或真实操作录屏反而稀缺 [经验推断]

## 格式与硬约束（篇幅、标题、标签、封面、结构、发布机制）

- **时长**：竖屏 9:16。工具演示类 15-45s 最稳，痛点+方案讲清即可；超过 60s 完播率明显掉。强钩子弱信息取舍上，抖音偏"钩子优先"，信息给到"让人想去主页/评论区问"即可，别指望一条视频讲全 6 个功能。
- **前 3 秒**：第 1 秒就要甩钩子（冲突/反转/悬念/利益），配文案+画面同步冲击 [检索所得]
- **文字卡点**：全程大字幕，关键词加粗放大，跟 BGM 鼓点卡；观众常静音刷，字幕即内容 [经验推断]
- **BGM**：用当下热门 BGM，越早蹭上升期音乐越吃推荐 [检索所得]
- **标题**：短、带钩子、埋垂类关键词（"AI 编程""Cursor""Claude Code""MCP"），方便系统打标签。标题里带个提问或反差。
- **话题标签**：3-5 个，混搭大词（#AI编程 #程序员）+ 精准词（#cursor #claudecode #mcp #独立开发者）[经验推断]
- **封面**：竖屏封面放一句最狠的钩子大字 + 一张"混乱 vs 清爽"对比图；封面文字≠标题，形成二次信息 [经验推断]
- **发布时间**：工作日 12-14 点（午休）、18-22 点（下班后），程序员受众晚上更活跃 [检索所得]
- **结构模板**：钩子（0-3s 痛点/结论）→ 冲突放大（3-8s 演示有多烦）→ 方案揭晓（8-20s aghub 一个动作搞定）→ 记忆点收尾（一句 slogan / 悬念钩评论）

## 自我推广的容忍度与原生包装方式

抖音对硬广的容忍度**低**，但对"分享型安利"容忍度高——关键是**别让它看起来像在卖，要看起来像在帮**。不能直接打广告（露 logo/二维码/引流会降权 [检索所得]），得走"发现一个好东西"人设：

- **产品当配角，痛点当主角**：视频 80% 在演"这有多烦"，20% 才轻描淡写"后来我用了个工具/我自己写了个东西"，重心永远在共鸣不在推销。
- **"我自己做的"是抖音稀缺的真诚牌**：独立开发者身份本身是钩子——"一个人写了个工具，管住了 22 个 AI 编程 agent"，做自己的故事而不是介绍软件。
- **导流走"评论区置顶 + 主页简介"而非视频口播**：视频里只留"名字",让人自己去搜/去主页，降低站外引流判定风险 [检索所得]。口播说"叫 aghub，开源的"比"点击链接下载"安全。
- **多条内容养垂直号**，别一条视频塞全部功能，一个功能一条视频，反而喂饱系统标签。

## 3-4 个原生开头钩子示例（该平台母语腔，可直接借用）

> 均为按抖音口播腔改写的原生开头，非某条真实爆款原文照抄。句式参考公开的"黄金三秒/开头模板"套路 [检索所得] 落地到 aghub。

1. **（痛点+反差型）** "别划走——你是不是也这样：Cursor 里配一遍 MCP，Claude Code 里再配一遍，Codex 里又配一遍……我受够了，所以我把它们全接到了一个地方。"

2. **（反常识结论型）** "我删了 22 个 AI 编程工具里的配置文件，一个都没重装。因为这个东西，一次配好，全同步。"

3. **（自曝身份+悬念型）** "一个独立开发者，为什么要花半年写一个'只管配置'的工具？因为我算了下，光重复配 MCP 我这辈子要浪费几百个小时。"

4. **（提问共鸣型）** "同时开着三个 AI 编程助手的人，你的 skill 是不是每换个工具就得重新搬一遍？这条告诉你怎么让它跟着你走。"

## 真诚⇄炒作该落在第几档

**3 档（偏真诚一侧，但钩子要狠）。**

理由：抖音的流量机制逼你在前 3 秒制造冲突，纯 1 档"平静真诚讲功能"会被完播率直接淘汰，所以不能像小红书/GitHub 那样克制。但 aghub 面向的是程序员——这群人**最反感浮夸和 AI 味**，你要是喊"震惊！这个神器颠覆 AI 编程"会被同行当笑话、掉信任。所以落在 3 档：**表达形式上放开（强钩子、痛点冲突、卡点、口语化"别划走"），价值主张上保持真诚（真实痛点、真实是我做的、不夸大、不承诺解决一切）。** 钩子可以炒，产品不能吹。

## aghub 在这个平台的切入角度

**角度 A（主推·痛点演示型）：**
- 选题：把"重复配置地狱"拍成即时冲突——分屏快速演示在 Cursor/Claude Code/Codex 里各配一遍同一个 MCP，报错、复制粘贴、抓狂，然后一个动作 aghub 全同步。
- 标题参考：《同时用好几个 AI 编程工具的人，这条能省你几百个小时》/《我再也不在每个 AI 编程工具里手动配 MCP 了》
- 结构：0-3s 痛点结论 → 3-10s 演示有多烦 → 10-25s aghub 一次同步 → 收尾"叫 aghub，开源，我自己写的"。

**角度 B（人设·独立开发者故事型）：**
- 选题：一个人为什么要写一个"管 22 个 AI 编程 agent 配置"的工具，把个人动机、真实痛点讲成故事，弱化功能罗列，强化"真诚做东西"的独立开发者形象。
- 标题参考：《一个独立开发者，用 Rust 写了个东西管住 22 个 AI 编程助手》
- 作用：养垂直人设、攒信任，为后续每个功能拆成单条视频铺路（Skills 可移植 / BYOM 自定义模型 / Usage 用量监控各出一条）。
