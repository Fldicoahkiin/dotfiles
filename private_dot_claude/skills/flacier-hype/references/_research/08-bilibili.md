# B站（视频）文风简报

> 被宣发项目：**aghub** —— One hub for every AI coding agent。统一管理 22+ AI coding agent（Claude Code、Codex、Cursor、Windsurf、Copilot、Gemini、OpenCode、Zed、Warp、Cline、RooCode…）配置的工具，CLI + Tauri 桌面 App。核心能力：跨 agent 统一管 MCP、可移植 Skills（.skill 包 + skills.sh 市场）、Claude Code 插件市场、BYOM 自定义模型 provider（key 存 OS keychain）、每 agent 独立选模型、Usage 用量监控。技术栈 Rust + Tauri 2，开源跨平台。
>
> 调研方法：4 轮中英文 WebSearch + 2 篇范例页 WebFetch（花叔「科技区爆款方法论」、2025 算法适配攻略）。可操作方法论多为 [检索所得]；B站 社区腔调、观众心态、独立开发者内容真实反响等结合社区认知，标 [经验推断]。
>
> **给 Flacier 的一句前情**：你上一条 B站 视频流量差、钩子弱。B站 是「完播率 + 前 3 秒」双重绞杀的平台——算法在 0-3 小时初测期若完播率 < 40%、点赞率 < 5%，直接停止推送 [检索所得]。所以这份简报把最多篇幅压在**前 15 秒钩子**和**封面标题**上，这两处是你上次翻车、也是这次唯一值得死磕的地方。

## 原生语感（这里的人到底怎么说话、什么调性）

B站 科技区的原生腔是「懂哥之间平视聊天」，不是抖音那种「家人们注意看」的吆喝，也不是公众号那种端着的科普腔。UP 主默认观众和自己一样是折腾党，所以说话可以放心用行话（MCP、agent、keychain 直接讲不用解释到幼儿园水平），但态度要平——是「我踩过这坑，分享给你」而不是「我来教你」。观众极度反感被当韭菜、被当小白，一旦嗅到「引流卖课」味立刻弹幕刷「恰烂饭」「典」「注意看这个男人叫小帅」[检索所得 + 经验推断]。真诚的自嘲、真实的翻车过程、敢说竞品好话，反而是这里的硬通货。

## 什么内容能起量（越具体越好）

- **「我受够了 X，于是自己做了个 Y」的独立开发叙事**：B站 吃这套，做东西的过程 > 东西本身。展示从痛点到成品的完整心路，比单纯 demo 功能起量高得多。[经验推断]
- **横评/对比**：「我把 5 个 AI coding agent 的配置全打通了，实测哪个最好用」——对比天然带完播钩子，观众想看结论。[检索所得：科技区偏好实测/对比]
- **保姆级实操 + 可直接抄的成果**：标题带「保姆级」「一个视频搞定」「手把手」是 B站 平台级偏好词，容易吃推荐。给出观众能立刻复用的东西（配置文件、命令、工作流）= 高收藏率 = 长尾流量。[检索所得]
- **数字化效率承诺**：「配置一次部署到 11 个 agent」「省下我每周 2 小时重复配置」——具体数字比形容词有力 10 倍。[检索所得]
- **反常识/揭秘**：「99% 重度用多 agent 的人都在重复配置，其实根本不用」这类前置结论。[检索所得]
- **踩坑/避雷向**：「我在 6 个 AI 工具里重复配了 3 个月 MCP，才发现有更好的办法」——痛点共鸣 = 弹幕 = 互动权重。[检索所得]
- **开源 + 真实**：明说开源、放 GitHub、承认还有 bug，B站 对「真·开源独立开发者」有天然好感滤镜。[经验推断]

## 什么显 AI 味 / 显尬 / 显硬广（要避开的雷）

- **前 3 秒空转**：上来「大家好我是 XX，今天给大家带来」= 观众划走。这几乎肯定是你上条视频钩子弱的病根。[检索所得]
- **AI 生成腔**：「在当今时代，AI coding agent 正变得越来越重要」「让我们一起来探索」这种正确的废话开场，B站 观众一秒识破，弹幕直接「AI 写的稿」。[经验推断]
- **功能罗列 PPT 朗读**：把 6 个功能挨个念一遍像发布会。观众要的是「解决了我什么问题」，不是 feature list。[检索所得]
- **标题党 + 封面骗点击**：夸张词「震惊」「不看后悔」会被 B站 降权，且内容对不上封面 = 弹幕「典」「诈骗」+ 完播暴跌。[检索所得]
- **硬切广告**：从内容突然生硬拐到「而这一切都靠我做的 aghub」= 恰饭感拉满。B站 观众能接受恰饭，但极度反感「烂恰」（生硬、避谈缺点、质量掉水平）。[检索所得]
- **数据造假/过度承诺**：吹「效率提升 100 倍」会被拆穿，翻车成本极高。[检索所得]
- **端着 / 爹味**：「你们不懂，我来告诉你们」。平视是底线。[经验推断]

## 格式与硬约束（篇幅、标题、标签、封面、结构、发布机制）[多为检索所得]

**时长**：科技/知识类 **5-10 分钟留存率最高**（约 31.5%，教育科普类可到 42%）。你这题材建议 **6-8 分钟**，别硬凑。

**标题公式**：`[痛点/疑问] + [解决方案/亮点]`，塞进「具体数字 + 情绪词 + 具体场景」。
- B站 偏好词：干货、保姆级、实测、一口气、手把手、一个视频。
- 反例：「我做了个管理 AI 工具的软件」→ 正例：「受够了在 11 个 AI 编程工具里重复配置，我用 Rust 写了个东西一次搞定」。

**封面（点击率生命线）**：
- 尺寸 1146×717，≥1080P；元素 ≤ 3 个。
- **必须加大字**，鲜艳色（大红/大黄/亮蓝），一排 ≤ 6 字、整封面 ≤ 8 字，字号 ≥ 24，手机端要清晰。
- 黄金法则：**一个核心卖点 + 一个冲突词**（例：「11 个 AI 工具｜配置一次搞定」「重复配置？没必要」）。
- 三种范式：效果展示型（成品截图+亮点字）/ 人物表情型（真人+夸张表情+核心字）/ 信息图型（对比数据）。

**标签**：5-8 个 = 1 核心词 + 3 长尾词 + 2 场景词。
- 核心：AI编程 / AI coding agent
- 长尾：Claude Code、Cursor、MCP、开源工具
- 场景：独立开发者、效率工具、Rust

**简介**：前两行是关键（列表页会露出），塞 3-5 个关键词 + 一句钩子 + GitHub 链接。别堆砌。

**发布机制**：
- 初测期 0-3 小时定生死（完播 <40% / 点赞 <5% 即断推）→ 爆发期 7-13 小时看互动深度（弹幕、评论、三连）→ 长尾期 1-30 天，约 10% 优质内容进长尾池、冷门垂类可「考古式爆发」。
- 最佳发布：**工作日晚 20:00-21:00**（中长视频消费窗口）。
- 视频结构模板（8 分钟版，压缩自花叔 12 分钟模板）：
  ```
  00:00-00:20  钩子 + 价值承诺（+ 新号一句自我介绍）
  00:20-01:30  痛点铺陈：多 agent 重复配置有多烦
  01:30-04:30  核心第一段：现场演示配一次 → 部署到全部 agent（信息密度最高）
  04:30-05:00  节奏切换点（一句自嘲/翻车/转场缓冲）
  05:00-07:00  核心第二段：Skills 跨 agent 共享 / BYOM / Usage 监控挑一个深挖
  07:00-07:40  总结 + 观点升华（为什么该有这么个 hub）
  07:40-08:00  互动引导 + 下期预告
  ```
- 每 3-5 分钟埋一个弹幕互动点或情绪转折，别出现 2 分钟冷区。

## 自我推广的容忍度与原生包装方式

**容忍度：高，但有条件。** B站 是所有中文平台里对「作者自荐自己作品」最友好的——只要你**是真的做了东西**、**开源**、**讲得真诚**，观众不但不反感，还会「让他恰」「这波不亏」。一项 2.6 万人投票里近半用户表示「只要内容好就接受推广」，但**软广接受度最低（仅 9.22%）——B站 观众宁可你直说「这是我做的」，也讨厌藏着掖着装客观测评** [检索所得]。这对独立开发者是极大利好：**你根本不用装成第三方，大方承认「这是我写的开源工具」反而加分。**

**原生包装方式**：
- **把广告变成故事**：主线是「我作为多 agent 重度用户的真实痛苦 → 我怎么一步步解决 → 顺便就成了 aghub」。工具是叙事的自然产物，不是插播。
- **先给价值，工具垫后**：整条视频先讲清楚「跨 agent 管 MCP/skill 这件事本身怎么做、有哪些坑」，观众学到东西了，最后说「我把这套封装成了开源工具，链接放简介」。给了社交货币，推广就顺。
- **敢说缺点/竞品好话**：主动说「目前还只支持 xx」「某某场景你直接手动改配置也行」——这一句真诚顶十句吹。B站 观众对「避谈缺点」零容忍。
- **恰饭引导放在内容高潮后**，不是硬结尾；「觉得有用的话 GitHub 给个 star，是对独立开发者最大的鼓励」这种诚实话术，比「记得三连」自然。

## 3-4 个原生开头钩子示例（前 15 秒，B站 科技区母语腔，可直接借用）

1. **痛点共鸣 + 反常识**
   > 「我电脑里装了 11 个 AI 编程工具——Claude Code、Cursor、Copilot、Codex 全都有。然后我发现一件很蠢的事：同一个 MCP，我在每个工具里配了一遍，配了整整十一遍。今天这个视频，就是我怎么让这十一遍变成一遍。」

2. **视觉冲击 + 数字**（开头直接放屏录）
   > 「注意看这个命令。我敲一次，MCP 配置、skill、模型 key，同步部署到我全部 11 个 AI coding agent。以前这事我要手动改 11 个配置文件——今天我用 Rust 写的这个开源工具，一行搞定。」

3. **翻车/自嘲式**（B站 最吃这套）
   > 「三个月前我换了台新电脑，重新配 AI 编程环境。Claude 一套、Cursor 一套、Codex 又一套……配到第三个的时候我人麻了：为什么 2026 年了，我还在给六个工具重复贴同一份配置？于是我干脆自己写了个东西。」

4. **痛点设问 + 价值前置**
   > 「如果你也同时在用好几个 AI 编程工具，你一定被这件事烦过：MCP、skill、模型 key，每换一个工具就得重配一遍。这视频我给你一个彻底的解法——而且是开源的，看完你就能自己上手。」

> 通用要点：15 秒内必须出现「多个 AI 工具」+「重复配置的痛」+「有个解法」三件套；能上手就上手直接屏录展示成果，B站 科技区视觉冲击型钩子留存最稳。

## 真诚⇄炒作该落在第几档

**第 2 档（偏真诚克制，略带钩子设计）。**

理由：B站 科技区观众的雷达是所有中文平台里最灵的——恰烂饭、标题党、AI 稿一秒识破，翻车即掉粉。你的人设（真诚、独立开发者气质）和这里的原生审美天然契合，硬炒只会自毁。但纯真诚（第 1 档）又救不了你上次「钩子弱、流量差」的病：B站 前 3 秒和封面必须有设计感、有冲突词、有数字，这部分要「工程化地用力」。所以落点是**内容与态度保持第 1-2 档的真诚（开源、承认缺点、平视），但钩子和封面标题按第 3 档的强度去打磨**——真诚是底色，钩子是技术活，两者不矛盾。

## aghub 在这个平台的切入角度（1-2 个具体选题/标题）

**选题 A：独立开发者叙事（主推，最贴 Flacier 人设、最吃 B站）**
- 标题：**「受够了在 11 个 AI 编程工具里重复配置，我用 Rust 写了个开源工具一次搞定」**
- 结构：痛点铺陈（多 agent 环境有多碎）→ 现场演示一次配置全量部署 → 挑 1-2 个亮点深挖（跨 agent 共享 Skills / BYOM key 存 keychain）→ 开源自荐 + 邀请共建。
- 封面：左边真人/表情 + 右边大字「11 个 AI 工具 · 配一次就够」，冲突词用「重复配置？没必要」。
- 为什么：把「我做了个工具」讲成「我作为重度用户的自救过程」，广告感最低、共鸣最高，且直击 aghub 真实痛点。

**选题 B：横评/科普向（引流更广、破圈潜力大）**
- 标题：**「我把 Claude Code、Cursor、Codex… 全打通了：一份 MCP 配置，喂给所有 AI 编程工具」**
- 结构：先当科普讲清「跨 agent 统一管 MCP / skill 这件事本身」的痛点和门道（给足社交货币）→ 演示 aghub 怎么实现 → 结尾自然带出「这套我封装成了开源工具」。
- 为什么：科普/横评在 B站 搜索流量和长尾都更好，把工具垫在知识后面，恰饭感被稀释到最低，适合冷启动破圈。

> 落地提示：无论 A/B，第一条视频建议选 A——独立开发者真实故事的完播和情感浓度更高，也最能修复上次「钩子弱」的问题；B 作为第二条承接搜索长尾。
